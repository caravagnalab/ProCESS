# Loading a phylogenetic forest

This method loads a phylogenetic forest from a file.

## Usage

``` r
load_phylogenetic_forest(filename, quiet)
```

## Arguments

- filename:

  The path of the file from which the phylogenetic forest must be
  loaded.

- quiet:

  An optional Boolean flag to avoid the progress bar (default: `FALSE`).

## Value

The loaded phylogenetic forest
