# Generating phylogenetic forests

A mutation engine can label every node of a samples forest by mutations
and produce a consistent phylogenetic forest.

## Details

The mutations are randomly generated according to three factors:

1.  the mutational rates of the species involved in the samples forest

2.  the genotypical specification of the mutants involved in the sample
    forest, i.e., the somatic mutations characterising the mutant
    genotypes

3.  the SBS and ID signatures active along the species simulation

The data of points 1 and 2 are provided to the mutation engine by the
method
[`MutationEngine$add_mutant()`](https://caravagnalab.github.io/ProCESS/1.3/reference/MutationEngine-cash-add_mutant.md).
Instead, the active signatures are defined by using the method
[`MutationEngine$add_exposure()`](https://caravagnalab.github.io/ProCESS/1.3/reference/MutationEngine-cash-add_exposure.md).

The initialisation of a
[`MutationEngine`](https://caravagnalab.github.io/ProCESS/1.3/reference/MutationEngine_class.md)
object requires a reference sequence and the SBS and ID mutational
signatures. An SBS index and a ID index of the reference sequence are
then automatically built. This process may take time depending on the
size of the reference sequence. Hence, the downloaded files together
with the built indices are saved on the disk for subsequent
[`MutationEngine`](https://caravagnalab.github.io/ProCESS/1.3/reference/MutationEngine_class.md)
constructions.

The objects of this class are generated by the function
[`MutationEngine()`](https://caravagnalab.github.io/ProCESS/1.3/reference/MutationEngine.md)
and provide the following methods and properties:

- [`add_exposure()`](https://caravagnalab.github.io/ProCESS/1.3/reference/MutationEngine-cash-add_exposure.md)
  adds exposures to the mutation engine.

- [`add_mutant()`](https://caravagnalab.github.io/ProCESS/1.3/reference/MutationEngine-cash-add_mutant.md)
  adds a mutant genomic specification to the mutation engine.

- [`change_rates_from()`](https://caravagnalab.github.io/ProCESS/1.3/reference/MutationEngine-cash-change_rates_from.md)
  changes the passenger rates from a specified time.

- [`get_SNV_signatures()`](https://caravagnalab.github.io/ProCESS/1.3/reference/MutationEngine-cash-get_SNV_signatures.md)
  returns the SNV signatures.

- [`get_active_germline()`](https://caravagnalab.github.io/ProCESS/1.3/reference/MutationEngine-cash-get_active_germline.md)
  returns the active germline subject.

- [`get_genome_info()`](https://caravagnalab.github.io/ProCESS/1.3/reference/MutationEngine-cash-get_genome_info.md)
  returns a data frame reporting reference genome information.

- [`get_germline_subjects()`](https://caravagnalab.github.io/ProCESS/1.3/reference/MutationEngine-cash-get_germline_subjects.md)
  returns the available germline subjects.

- [`get_indel_signatures()`](https://caravagnalab.github.io/ProCESS/1.3/reference/MutationEngine-cash-get_indel_signatures.md)
  returns the indel signatures.

- [`get_known_drivers()`](https://caravagnalab.github.io/ProCESS/1.3/reference/MutationEngine-cash-get_known_drivers.md)
  returns the data frame of the known driver mutations.

- [`get_population_descriptions()`](https://caravagnalab.github.io/ProCESS/1.3/reference/MutationEngine-cash-get_population_descriptions.md)
  returns the available population descriptions.

- [`get_species_info()`](https://caravagnalab.github.io/ProCESS/1.3/reference/MutationEngine-cash-get_species_info.md)
  returns the registered species and their rates.

- [`infinite_sites_model`](https://caravagnalab.github.io/ProCESS/1.3/reference/MutationEngine-cash-infinite_sites_model.md)
  is a Boolean property to enable/disable the infinite sites model.

- [`place_mutations()`](https://caravagnalab.github.io/ProCESS/1.3/reference/MutationEngine-cash-place_mutations.md)
  places mutations on a
  [`SampleForest`](https://caravagnalab.github.io/ProCESS/1.3/reference/SampleForest.md)
  object and generates a
  [`PhylogeneticForest`](https://caravagnalab.github.io/ProCESS/1.3/reference/PhylogeneticForest.md)
  object.

- [`set_germline_subject()`](https://caravagnalab.github.io/ProCESS/1.3/reference/MutationEngine-cash-set_germline_subject.md)
  sets the active germline subject.
