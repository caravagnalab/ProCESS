# Getting the indel signatures

This method returns the available indel signatures.

## Value

A data frame containing the available indel signatures.

## Details

The signatures are returned in a data frame containing the available
indel signatures together with the corresponding mutation probability.
The first column ("Type") describes a mutation in a context, while each
of the remaining columns contains the probabilities of the mutations for
one of the available indel signatures.
